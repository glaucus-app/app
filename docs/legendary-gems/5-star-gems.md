## Column Definitions

| Column | Description |
|--------|-------------|
| **Gem Name** | Name of the legendary gem |
| **Type** | OFF (Offensive), DEF (Defensive), or ALL (Universal) |
| **Effect Type** | Category of effect (permanent, Buff, DOT, LOC, etc.) |
| **Dmg Type** | Damage type if applicable |
| **Strifed** | Whether effect is reduced in Battlegrounds |
| **Gem Effect** | Description of the effect |
| **Max** | Maximum value at Rank 10 |
| **Duration** | Effect duration in seconds |
| **Cooldown** | Cooldown in seconds |

## 5-Star Special Features

### Resonance Slots
5-Star gems unlock special slots for resonance gems at higher ranks:

| Rank | Slots Unlocked |
|------|----------------|
| 4 | Slots 1-2 (2-Star gems) |
| 6 | Slot 3 (R6+ 2-Star gem) |
| 7 | Slot 4 (R7+ 5-Star gem) |
| 8 | Slot 5 (R8+ 5-Star gem) |

### Quality Bonuses
5-Star gems have quality ratings that affect stats:

| Quality | CR per Rank | Resonance per Rank |
|---------|-------------|-------------------|
| 2/5 | Lowest | 840-1080 |
| 3/5 | Medium | 880-1120 |
| 4/5 | High | 920-1160 |
| 5/5 | Maximum | 1020-1260 |
