## Gem Categories

### By Star Rating

| Category | Description |
|----------|-------------|
| **1-Star Gems** | Common legendary gems, easier to upgrade |
| **2-Star Gems** | Mid-tier gems with stronger effects |
| **5-Star Gems** | Powerful gems with unique mechanics and resonance slots |

### By Effect Type

| Type | Description |
|------|-------------|
| **OFF** | Offensive effects (damage increases) |
| **DEF** | Defensive effects (damage reduction, shields) |
| **ALL** | Universal effects affecting multiple stats |
| **DOT** | Damage-over-time effects |
| **LOC** | Loss of Control effects (stun, freeze, etc.) |
| **Buff** | Temporary stat increases |
| **Debuff** | Effects applied to enemies |

## Key Mechanics Summary

### Strife (Battlegrounds)
- Most legendary gem effects are **strifed by 70%** in Battlegrounds
- Some gems have exceptions and are not strifed
- Strife status is indicated in gem tables

### Duration Extensions

| Effect Type | Extension Source |
|-------------|------------------|
| **Buffs** (green) | Vithu's 2pc (+30%), Beneficial Duration affixes |
| **CC/LOC** (yellow) | Baron's 2pc, Potency stat |
| **DOT** (yellow) | Baron's 2pc, Potency stat |
| **Debuffs** (yellow) | Baron's 2pc, Potency stat |

> **Note**: Some gems (e.g., Mother's Lament, Crimson Behelit) do not benefit from Vithu's 2pc buff.
