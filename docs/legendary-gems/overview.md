# Legendary Gems Core Mechanics

> Overview of how legendary gem effects work and interact with game systems.

---

## Effect Types and Duration Extensions

### Buffs

**Color in tables: Green**

The duration of a buff that's triggered by a legendary gem can usually be prolonged by:

| Source | Extension |
|--------|-----------|
| Vithu's 2pc | +30% |
| Magic Affixes (Beneficial Duration) | Variable |

> ⚠️ **Exception**: Some gems do NOT benefit from Vithu's 2pc buff:
> - Mother's Lament
> - Crimson Behelit

### Control Effects (CC/LOC)

**Color in tables: Yellow**

The duration of control effects (slow, chill, stun, freeze) can be prolonged by:

| Source | Extension |
|--------|-----------|
| Baron's 2pc | Variable |
| Potency Stat | Variable |

### Damage-over-Time (DOT)

**Color in tables: Yellow**

The duration of DOT effects from legendary gems can be prolonged by:

| Source | Extension |
|--------|-----------|
| Baron's 2pc | Variable |
| Potency Stat | Variable |

### Debuffs

**Color in tables: Yellow**

The duration of debuffs (Vulnerability, Armorbreak) can be prolonged by:

| Source | Extension |
|--------|-----------|
| Baron's 2pc | Variable |
| Potency Stat | Variable |

## Strife (Battlegrounds)

Usually legendary gem effects are **strifed by 70%** in Battlegrounds.

> **Exceptions**: Some gems have effects that are not strifed. Check individual gem tables for "not strifed" or "n.r." (not relevant) designations.

### Strife Status in Tables

| Status | Meaning |
|--------|---------|
| `strifed` | Effect is reduced by 70% in BG |
| `not strifed` | Effect applies at full strength in BG |
| `n.r.` | Not relevant / doesn't apply |

## Effect Categories

| Category | Description |
|----------|-------------|
| **OFF** | Offensive - increases damage output |
| **DEF** | Defensive - reduces damage taken or provides protection |
| **ALL** | Affects multiple stats or categories |
| **permanent** | Always active, no duration or cooldown |
| **conditional** | Activates under specific conditions |
| **Buff** | Temporary positive effect on the player |
| **Debuff** | Negative effect applied to enemies |
| **DOT** | Damage over time |
| **LOC** | Loss of Control (stun, freeze, etc.) |
| **TLOC** | Targeted Loss of Control |
| **Summon** | Creates a minion or clone |
| **Conjure** | Creates a temporary effect or object |
| **Damage** | Direct damage effect |
| **Heal** | Healing effect |

## Key Stats

### Beneficial Duration
- Extends the duration of buffs on yourself
- Works with most gem-triggered buffs
- Stacks with Vithu's 2pc bonus

### Potency
- Extends the duration of:
  - Control effects (CC/LOC)
  - Damage-over-time effects
  - Debuffs on enemies

---

## Gem Star Ratings

### 1-Star Gems
- Easiest to obtain and upgrade
- Lower base stats and effects
- Good for early game and budget builds

### 2-Star Gems
- Medium rarity and upgrade cost
- Balanced power level
- Many offer unique mechanics

### 5-Star Gems
- Highest rarity and upgrade cost
- Most powerful effects
- Unlock Resonance slots at Rank 4
- Can have 5 resonance gem slots at high ranks
