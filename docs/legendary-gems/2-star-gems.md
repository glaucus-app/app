## Column Definitions

| Column | Description |
|--------|-------------|
| **Gem Name** | Name of the legendary gem |
| **Type** | OFF (Offensive), DEF (Defensive), or ALL (Universal) |
| **Effect Type** | Category of effect (permanent, Buff, DOT, LOC, etc.) |
| **Dmg Type** | Damage type if applicable |
| **Strifed** | Whether effect is reduced in Battlegrounds |
| **Gem Effect** | Description of the effect |
| **Max** | Maximum value at Rank 10 |
| **Duration** | Effect duration in seconds |
| **Cooldown** | Cooldown in seconds |

### Special Effect Types
- **Buff*** = Does not benefit from Vithu's 2pc bonus
