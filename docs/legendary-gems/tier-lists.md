## Tier Explanation

| Tier | Description |
|------|-------------|
| **S** | Best-in-slot gems, highly recommended for optimal performance |
| **A** | Excellent choices, strong performers in most situations |
| **B** | Good options, viable with specific builds or playstyles |
| **C** | Situational picks, may work in niche scenarios |
| **D** | Generally not recommended, outclassed by other options |
